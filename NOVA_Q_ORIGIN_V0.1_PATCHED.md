11. TWIN / SYNCHRONIZATION ORIGIN
===============================================================================

The Twin principle follows from the distinction:

SAME_VALUE ≠ SAME_FORM

and:

SAME_VALUE ≠ SAME_SIZE

Therefore:

TWIN =
distinct structures connected by a declared value relation.

The relation must be testable.

A Twin claim is invalid if the invariant is defined so broadly
that every transformation automatically passes.

12. NON-TRIVIALITY RULE
===============================================================================

Every invariant used in NOVA Q testing must permit failure.

Therefore:

VALID_INVARIANT
requires:

PASS_CONDITION
+
FAIL_CONDITION

If:

∀A,B : V(A) ≈ V(B)

then the invariant is trivial for that test.

Such an invariant cannot support a non-trivial validation claim.
